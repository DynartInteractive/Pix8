# Pix8 1.7.0 — linked cels

Pix8 is a 256-color indexed pixel art editor built around VGA-era workflows:
one shared 256-entry palette for the whole document, independent layers,
frame animation, and a GrafX2-style palette editor.

This release brings **linked cels** to the animation timeline — the
Aseprite-style feature where several frames share one image, so a held pose or
a static background only has to be drawn (and stored) once.

## New: linked cels

A **cel** is one layer's image on one frame. Two frames can now hold the *same*
cel — edit either one and both update, because there is only one image behind
them.

- **Add linked frame** (next to *Add frame* in the frame panel) creates a frame
  that shares every cel of the current one.
- **Shift+click** the timeline to select a frame range, then **Link** or
  **Unlink**.
- Link and Unlink act on the **active layer** across the selected frames. A cel
  is (layer × frame), so linking a whole frame isn't a thing — you link a
  layer's image across frames. That also means you can link a static background
  layer across a whole tag while the character layer stays unique per frame.
- The bar under the thumbnails shows link runs **for the active layer**, so
  switching layers changes what it shows.
- **Unlink** clones the cel: the frame keeps the pixels it was showing and
  stops following its siblings.
- Link and Unlink are undoable.

Also new: **`,`** and **`.`** step to the previous / next frame.

## ⚠️ Animated `.pix8` files from earlier versions will not open

Animated `.pix8` files now store a cel table plus per-frame cel-id lists
instead of a full copy of every layer on every frame. Linked frames therefore
cost no extra bytes, and even unlinked animations get smaller — but there is no
reader for the old layout.

**Non-animated `.pix8` files are unaffected** and open normally.

This landed in a minor version rather than 2.0.0 because no animated `.pix8`
files existed in the wild, and 2.0.0 is reserved for 24-bit truecolor support.

## Fixed in this version

- **Undo after moving multiple layers restores all of them.** Move and
  arrow-key nudge act on every layer in the multi-layer selection, but undo
  only snapshotted the active layer — so the other layers stayed displaced,
  with no way to put them back.
- **Layer borders no longer march.** With *Show Border* on and a selection
  active, the dashed layer outlines animated along with the selection's
  marching ants.

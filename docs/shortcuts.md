# Keyboard Shortcuts

## Tools

| Key | Action |
|-----|--------|
| V | Move tool |
| B | Brush tool |
| E | Eraser tool |
| I | Color Picker tool |
| U | Rectangle tool |
| O | Ellipse tool |
| G | Flood Fill tool |
| M | Rectangle Select tool |
| Shift+M | Ellipse Select tool |
| Ctrl+M | Mirror tool |
| T | Free Transform tool |
| W | Text tool |
| X | Swap FG/BG colors |
| 1 | Reset brush to default (1px) |

## View and animation

| Key | Action |
|-----|--------|
| +/- | Zoom in/out |
| Middle mouse drag | Pan canvas |
| Ctrl+' | Toggle grid |
| Ctrl+Shift+' | Toggle snap to grid |
| Alt+R | Toggle rulers |
| Ctrl+; | Toggle guides |
| Space | Play Tag / Stop (animation) |
| , / . | Previous / next frame (animation) |

## Selection and clipboard

| Key | Action |
|-----|--------|
| Ctrl+A | Select all |
| Ctrl+D | Deselect |
| Enter | Commit free transform |
| Escape | Cancel / deselect / commit floating selection |
| Delete | Clear selected pixels |
| Ctrl+B | Set brush from selection |
| Ctrl+C | Copy |
| Ctrl+Shift+C | Copy merged (all layers) |
| Ctrl+X | Cut |
| Ctrl+V | Paste onto the current layer as a floating selection (centered) |
| Ctrl+Shift+V | Paste in place, as a floating selection |
| Ctrl+Alt+V | Paste as a new layer |

## File and history

| Key | Action |
|-----|--------|
| Ctrl+Z | Undo |
| Ctrl+Shift+Z | Redo |
| Ctrl+S | Save project |
| Ctrl+Shift+E | Export as... |
| Ctrl+O | Open file |

## While dragging

| Modifier | Effect |
|-----|--------|
| Shift (brush, eraser) | Straight line from the last pixel drawn |
| Shift (shapes, selections) | Square / circle |
| Ctrl (lines, Free Transform rotation) | Snap to 22.5-degree steps |
| Ctrl+drag (selection) | Add to the selection |
| Alt+drag (selection) | Subtract from the selection |
| Right mouse button (brush) | Draw with the background color |
